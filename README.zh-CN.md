# Volcminer D1 mini — 实验性风扇修复与 LED 控制

[English](README.md)

本项目为 **D1 Mini / D1 Mini Pre Ethernet** 提供非官方实验性固件，基于厂商 **2025-11-10 13:22:38** 版本。包含两项风扇控制修复和独立的 LED 控制，LED 设置可在重启后保留。

## 修复内容

1. **PWM 被旧的自适应下限锁住。** 持续降温时，原控制器虽然尝试降低 PWM，却可能立即将其限制回之前记录的下限。补丁使该下限随确认后的降速步骤一起降低，不再覆盖刚刚降低的 PWM。
2. **从 99% 进入紧急全速后无法退出 100%。** 原代码在进入 100% 前保存 PWM，冷却后恢复为 `保存值 + 1`。如果保存的是 99，恢复结果仍为 100，此路径会不断重复。补丁直接恢复保存值，让正常的降温调速逻辑继续工作。

配置的频率、电压、内存参数、矿池、温度阈值、降速延时和降速步长均未修改。强制保护性全速机制仍保留，但这并不代表所有保护路径都已完成实机验证。

## LED 控制

在语言选择器左侧新增两个开关，外观与 Volcminer 界面保持一致：

- **ASIC LED** 仅控制闪烁的绿色状态指示灯。**Off** 停止绿灯闪烁；**On** 恢复正常的自动闪烁。红色报警灯继续由原系统自动控制，蓝灯和黄灯保留原有的事件触发行为。
- **Ethernet LED** 可开启或关闭网口指示灯，不会关闭网络连接。

两项设置均可保存，并在设备重启后自动恢复。切换 LED 不会重启挖矿进程，也不会更改挖矿设置。

## 验证结果与限制

- 补丁通过全部 **16 项 ARM 模拟测试**；原始程序可复现旧下限锁定和 `99 → 100 → 100` 问题。
- **2026-10-18** 已通过标准网页更新功能安装到 **一台 D1 Mini Pre Ethernet**，两块算力板正常启动并恢复挖矿。
- 短时间实机观察中，PWM 从 50 降到 44，随后在日志温度达到 65 °C 时升至 52。后续状态页面显示风扇约 **2640–2670 转/分**、PCB 温度 **61/60 °C**、算力约 **2.21–2.33 GH/s**，相应采样时拒绝份额为 0。
- 启动时出现过风扇警告，之后显示 `check_fan_speed OK`；启动早期另有一次风扇错误。所检查的当前日志中未发现后续同类错误再次出现。

- **2026-10-23** 已在同一设备上安装 LED 版本并完成重启测试。重启前已回读并校验写入的根文件系统镜像。重启后两个开关均正常工作，机主现场确认保存的 Off 设置已自动恢复。切换 LED 时挖矿持续运行，有效份额增加，挖矿进程未重启。最终观测值约为 **2.23 GH/s**、PCB 温度 **55/54 °C**、风扇 **2970/2970 转/分**、**接受 278 / 拒绝 0 个份额**。这些数据仅代表当时的状态，并非性能保证。启动阶段曾出现电源读取及风扇警告，之后恢复正常运行。

**尚未证明长期稳定性，也不能确认用户遇到的偶发故障已彻底消失。** 未在实机上故意触发紧急高温场景。仅在一台设备上验证，当前证据确认了软件缺陷及观测到的运行情况，不能保证解决所有导致风扇全速的问题。
